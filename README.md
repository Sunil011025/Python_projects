# 🐍 Python Mini Projects Collection

This repository contains a collection of beginner-friendly Python projects created to practice programming concepts, logic building, and problem-solving.

---

## 📁 Projects Included

### 🧮 Calculator

* Perform basic arithmetic operations
* Simple user input handling

📄 File: `Calculator.py`

---

### 🔢 Guess the Number Game

* Random number generation
* User tries to guess the correct number
* Feedback system (Too high / Too low)

📄 File: `Guess the number.py`

---

### 🎮 Hangman Game

* Word guessing game
* Limited attempts
* Uses ASCII art for stages

📄 Files:

* `Haangman_game.py`
* `hangman_stages.py`

---

### 🔐 Caesar Cipher

* Encrypt and decrypt messages
* Shift-based encoding technique

📄 File: `caeser_chiper.py`

---

### 🏦 Silent Auction

* Simulates a bidding system
* Determines highest bidder

📄 File: `Silent auction .py`

---

### 🔑 Password Generator

* Generates random secure passwords
* Uses letters, numbers, and symbols

📄 File: `password generator.py`

---

### ✊ Rock Paper Scissors Game

* Classic game vs computer
* Randomized computer moves

📄 File: `rock_paper_scissor_game.py`

---

### 📊 Data Info Script

* Basic data handling and display

📄 File: `data_info.py`

---

### ☕ Coffee Machine Simulation

* Simulates a coffee vending machine
* Resource management logic

📄 Files:

* `Coffee_making_machine.py`
* `Algorithm_Coffee_making_machine.py`

---

### 📉 Higher Lower Game

* Compare values and guess higher/lower

📄 File: `Higher_Lower_game.py`

1. Clone the repository:

```bash

```

2. Navigate to the folder:

```bash
cd Snake-Game
```

3. Run any file:

```bash
py filename.py
```
